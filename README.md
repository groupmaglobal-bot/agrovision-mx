# AGROVISION_MX

**Del campo al dato.** Landing page de AGROVISION_MX: el medio que explica cómo la tecnología está cambiando el campo mexicano.

- Sitio estático: un solo `index.html` (HTML + CSS inline, fuente Inter).
- Publicado con **GitHub Pages** (rama `main`, carpeta `/`).
- Instagram: [@agrovision_mx](https://www.instagram.com/agrovision_mx/)

## Editar en local (Windows)

```powershell
git clone https://github.com/groupmaglobal-bot/agrovision-mx.git
cd agrovision-mx
start index.html
```

Haz tus cambios, luego:

```powershell
git add .
git commit -m "update landing"
git push
```

GitHub Pages se actualiza en 1–2 minutos.
